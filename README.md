# Garimpo da Casa

Site oficial do Garimpo da Casa, criado para transformar o tráfego do Instagram em entradas na comunidade de achados no WhatsApp e compras diretas no catálogo curado.

## Objetivo

A página apresenta a proposta da marca, prioriza a comunidade no mobile e organiza os produtos por categoria, com busca, filtros e links diretos para os anúncios.

## Estrutura

```text
Garimpo-da-Casa/
├── index.html      # conteúdo e estrutura da página
├── style.css       # identidade visual e responsividade
├── script.js       # animações, busca, filtros e ano automático
├── images/         # imagens da marca e dos produtos
└── README.md
```

## Atualizações importantes

### Catálogo de produtos

- Produtos separados em Cozinha, Organização, Limpeza, Banheiro e Tecnologia.
- Busca por nome ou finalidade e filtros de categoria.
- Cards com imagem, preço de referência e acesso direto à oferta.
- No mobile, a comunidade aparece primeiro e o catálogo logo em seguida.

### Link da comunidade

Os três botões direcionam diretamente para a comunidade pelo link `https://chat.whatsapp.com/Dm7dQ9fmLK26oCGweuBvwB`.

### Instagram

O perfil configurado é [@garimpo_da_casa_](https://www.instagram.com/garimpo_da_casa_/).

### Identidade e SEO

- Título, descrição, Open Graph e URL canônica estão configurados para o GitHub Pages.
- A paleta combina verde profundo, dourado e tons de creme para transmitir confiança, oportunidade e cuidado com a casa.
- A página é responsiva, acessível por teclado e respeita a preferência de movimento reduzido.

## Publicação

O site é estático e não exige build. Com o GitHub Pages configurado para publicar a raiz da branch `main`, cada atualização enviada à branch será publicada automaticamente.
